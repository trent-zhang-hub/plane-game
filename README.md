# 经典飞机大战

基于 HTML5 Canvas 和原生 JavaScript 制作的竖版射击游戏，无需安装，打开即玩。

**🎮 在线游玩：https://trent-zhang-hub.github.io/plane-game/**

---

## 游戏玩法

- **移动**：鼠标移动 / 手机触屏拖动
- **炸弹**：键盘空格键 / 手机双击屏幕
- 击落敌机获得积分，拾取道具补给增强战力
- 3 条生命，耗尽后游戏结束

## 道具说明

| 道具 | 效果 |
|------|------|
| 子弹补给 | 升级为双发子弹，持续 15 秒 |
| 炸弹补给 | +1 炸弹 |

## 敌机类型

| 类型 | 血量 | 分值 |
|------|------|------|
| 小敌机 | 1 | 100 |
| 中敌机 | 6 | 200 |
| Boss | 20 | 1000 |

## 手机添加到主屏幕

用 Safari 打开游戏链接 → 点击底部分享按钮 → **添加到主屏幕**，即可像 App 一样全屏运行。
